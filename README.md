# 🌿 東洋医学・胃腸体質診断＆LINE通知システム

Lステップ（有料プラン）を解約し、**月額費用完全0円**で運用できる体質診断システムです。
スマホに最適化された綺麗な診断Web画面、上位2タイプまでの自動混合判定、Googleスプレッドシートへの回答ログ蓄積、LINEトークへの自動配信をすべて実現します。

---

## 📁 ファイル構成

```text
├── index.html           # 診断Webアプリのメイン画面（HTML）
├── style.css            # 和モダン・クリーンなデザインスタイルシート
├── app.js               # 診断フォーム進行・スコア集計・LIFF連携ロジック
├── diagnosis_data.js    # 設問一覧・スコア配点・結果テンプレート集（単一5種＋混合10種）
├── Code.js              # Google Apps Script (GAS) バックエンドコード
├── test_diagnosis.js    # 診断ロジックの単体テスト
└── README.md            # 本マニュアル（導入手順書）
```

## 🚀 導入手順（ステップ・バイ・ステップ）

設定は以下の **3ステップ（約10〜15分）** で完了します。

### 【ステップ1】Googleスプレッドシート＆GASの準備（3分）

1. [Googleスプレッドシート](https://sheets.new) で新しいスプレッドシートを作成します。
   - シート名は「**【公式LINE】体質診断 回答ログ**」などに設定します。
2. 上部メニューの **「拡張機能」 ➔ 「Apps Script」** をクリックします。
3. もともと入っているコードを消去し、[`Code.js`](file:///Users/tanakakazuhiro/src/lstep/Code.js) の内容をすべて貼り付けて保存（フロッピーアイコンまたは Cmd+S）します。
4. エディタ上部の関数選択プルダウンで **`setupSpreadsheet`** を選び、**「実行」** をクリックします。
   - 初回のみ「アクセス権の承認」を求められるので、「許可を確認」➔ ご自身のアカウント ➔「詳細」➔「〇〇（安全ではないページ）に移動」➔「許可」をクリックします。
   - 実行が完了すると、スプレッドシートに **「回答ログ」シート** と **「結果テンプレート設定」シート** が自動作成されます！
5. 右上の青い **「デプロイ」 ➔ 「新しいデプロイ」** をクリックします。
   - 種類の選択（歯車アイコン）: **「ウェブアプリ」**
   - 説明: `v1` など
   - 次のユーザーとして実行: **「自分」**
   - アクセスできるユーザー: **「全員」**（※重要）
   - **「デプロイ」** をクリックします。
6. 発行された **「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）をコピーしておきます。

---

### 【ステップ2】LINE DevelopersでLIFFの作成（5分）

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログインします。
2. 既存の公式LINEに紐づくプロバイダーを選択（または作成）します。
3. **「新規チャネル作成」 ➔ 「LINEログイン」** を選択します。
   - アプリ名: `胃腸・体質診断`
   - アプリタイプ: `ウェブアプリ`
4. 作成したチャネル内の **「LIFF」** タブを開き、**「追加」** をクリックします。
   - LIFFアプリ名: `体質診断`
   - サイズ: **`Full`**（全画面表示）
   - エンドポイントURL: 本Webアプリを公開したURL（※GitHub Pages、Vercel、またはWebサーバーのURL）
   - Scope（スコープ）: `profile`, `chat_message.write`（トーク送信を許可する場合）にチェック
   - ボットリンク機能: `Normal` または `Aggressive`
5. 作成後に表示される **`LIFF ID`**（例: `1234567890-AbCdEfGh`）をコピーします。

---

### 【ステップ3】アプリの設定と公開（2分）

1. [`app.js`](file:///Users/tanakakazuhiro/src/lstep/app.js) の冒頭にある設定箇所を開きます：
   ```javascript
   const APP_CONFIG = {
     // LINE Developersで取得したLIFF IDを貼り付け
     liffId: 'ここにLIFF_IDを貼り付け', 
     // ステップ1でコピーしたGASのウェブアプリURLを貼り付け
     gasEndpointUrl: 'ここにGASのURLを貼り付け'
   };
   ```
2. 個別面談リンクなどを変更したい場合は、[`diagnosis_data.js`](file:///Users/tanakakazuhiro/src/lstep/diagnosis_data.js) の `SYSTEM_CONFIG` や `RESULT_TEMPLATES` 内のURLを更新します。
3. ファイル一式（`index.html`, `style.css`, `app.js`, `diagnosis_data.js`）を、GitHub Pages（無料）やVercel（無料）、お持ちのサーバー等にアップロードします。

## 🎯 流入元ごとのURL使い分け（YouTube / 𝕏 など）

LINEで開くLIFFのURLの後ろに `?from=〇〇` をつけるだけで、**ユーザーが手動で選ばなくても流入元が自動判定＆記録**されます。

| 設置場所 | 設置するURL | 自動記録される流入元 |
| :--- | :--- | :--- |
| **YouTube** の概要欄 | `https://liff.line.me/{LIFF_ID}?from=youtube` | YouTube（胃弱さん向け動画） |
| **𝕏 (Twitter)** のプロフィール | `https://liff.line.me/{LIFF_ID}?from=x` | 𝕏 / Twitter（胃弱さん向け発信） |
| **Instagram** のリンク | `https://liff.line.me/{LIFF_ID}?from=instagram` | Instagram |
| その他・直接アクセス | `https://liff.line.me/{LIFF_ID}` | 画面上で選択されたもの |

## 💬 LINE公式アカウントでの案内方法

### 1. 友だち追加時あいさつの設定
LINE Official Account Manager（LINE公式アカウント管理画面）の「応答設定」➔「友だち追加時あいさつ」に以下のように登録します：

> 友だち追加ありがとうございます！  
> 胃の専門家 カズ先生です😊  
>   
> まずはあなたの胃の不調の根本原因を知るために、  
> こちらの『無料 体質診断』を受けてみてくださいね👇  
> https://liff.line.me/{あなたのLIFF_ID}  
>   
> 診断結果に応じた専用の薬膳ガイドや胃のトレーニング動画をお届けします🎁

### 2. リッチメニューの設置
LINE公式アカウントのリッチメニューに「無料 体質診断を受ける」ボタンを配置し、リンク先にLIFFのURLを設定することで、いつでも誰でも診断を受けられるようになります。

## 💡 メリットと運用のポイント

1. **Lステップの月額費用が0円に**  
   GoogleスプレッドシートとGASを使うため、サーバー代・ランニングコストは永久に無料です。
2. **LINE配信通数を消費しない**  
   LIFFのトーク送信機能を使用しているため、LINE公式アカウントの月200通無料枠を消費しません。何千人に受診されても追加課金は発生しません。
3. **顧客台帳（CRM）の自動化**  
   誰が・いつ・どのSNSから来て・どんな胃の弱り（スコアとタイプ）を抱えているのかが、スプレッドシートに1行ずつ自動蓄積されます。
4. **メンテナンスが簡単**  
   解説文や動画URLの変更も、スプレッドシートまたは `diagnosis_data.js` を書き換えるだけでいつでも即時反映されます。
